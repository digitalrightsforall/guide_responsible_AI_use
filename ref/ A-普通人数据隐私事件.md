# 真实案例列表

- **事件名称与时间**：ChatGPT 会话分享索引事件（2025年7月–8月）。  
  **当事方与涉案工具**：美国 OpenAI 公司（ChatGPT）。  
  **具体侵害事实**：2025年7月，用户通过 ChatGPT 的共享链接功能分享的对话被谷歌等搜索引擎索引，导致数千条原本“私密”的聊天记录（包括求职简历、心理咨询内容等个人敏感信息）被公开搜索到。问题源于 OpenAI 短暂开放的 “Make this chat discoverable（使此对话可被搜索）” 功能，该功能默认让分享链接出现在搜索引擎索引中。结果，一些用户无意中将原本私密的对话暴露于公网。  
  **处理结果/文号**：OpenAI 于2025年8月1日紧急下线并撤销该功能，并与搜索引擎协作移除已索引内容（未见政府处罚）。  
  **来源**：TechCrunch 报道（T2，知名科技媒体）、Snyk 安全博客（T3，网络安全行业博客）。

- **事件名称与时间**：意大利隐私保护局对 OpenAI 的制裁决定（2024年11月；2026年3月撤销）。  
  **当事方与涉案工具**：意大利个人数据保护局（Garante）诉 OpenAI（ChatGPT）。  
  **具体侵害事实**：Garante 指控 OpenAI 在没有适当法律依据或用户同意的情况下，使用意大利用户的个人数据训练 ChatGPT，且未如实通报数据泄露及未提供充分隐私通知；对未成年人保护不足等。  
  **处理结果/文号**：2024年11月2日，Garante 发布第755号决定，对 OpenAI 处以高达1500万欧元罚款并责令公开宣传数据保护义务等整改措施。但 OpenAI 提起行政诉讼。2026年3月18日，罗马地方法院第4153/2026号判决撤销了上述制裁决定，OpenAI 无需支付罚款。  
  **来源**：Garante 通知（文号755/2024）（T1，官方文档摘要），Arena Digitale 报道（T2，意大利权威数字媒体）。

- **事件名称与时间**：美国 ChatGPT 隐私集体诉讼（2023年6月提起）。  
  **当事方与涉案工具**：美国网民（原告）诉 OpenAI（ChatGPT）与 Microsoft。  
  **具体侵害事实**：2023年6月28日，多名匿名原告在美国旧金山北加州联邦法院提起集体诉讼，指控 OpenAI 在训练 GPT-3.5/4.0 等模型时，大规模未获同意地“爬取”网络数据。诉讼称被告未经用户许可即“窃取数千亿字的私密信息”用于训练AI，包括姓名、联系方式、邮件、社交媒体数据、聊天记录、支付信息等个人信息。原告请求停止此类数据收集并赔偿损失。  
  **处理结果/文号**：该案以 3:23-cv-03199-JCS 号立案（ND CA, 2023年6月28日），目前仍在审理中（无最终判决）。  
  **来源**：VICE 报道（T2，美国知名新闻媒体）、联邦法院起诉状（T1，官方法律文书）。
